# 正式测评待办

## 背景

阶段 0 已建立固定脱敏样本和回归脚本，可作为历史参考。

生产化阶段需要重新设计测评体系。本文件只记录待办和约束，不输出正式测评方案。

## 待办

- 确认正式测评语料来源、脱敏规则和数据保留边界。
- 定义正式任务类型覆盖范围，包括代码修改、Review、问题排查、表结构影响分析和设计文档检索。
- 设计正式指标，不直接照搬阶段 0 的 Top5 / Top10 指标。
- 明确人工标注规范，包括有效命中、明显无关、来源不可追溯和文档过期的判定。
- 确认评测报告格式，包括样本级失败详情、指标趋势和版本对比。
- 决定是否保留 `scripts/run_mvp_evaluation.py` 作为历史回归脚本，或新增正式评测脚本。
- 评估真实项目 SQL 方言、目录结构和多仓库语料对评测覆盖的影响。

## 当前约束

- 不把单次演示效果作为正式测评结论。
- 不把无来源引用的结果计为有效工程上下文。
- 不把阶段 0 归档样本扩展成正式测评集，除非后续单独确认样本代表性。
- 正式评测文档待后续需求确认后再输出。
