## 保留原则

- 当前完成度和验收判断只看 `phase1-current-status.md`，不从个人进展或阶段汇报推断。
- 原始任务边界只看 `post-mvp-todo.md`；当前实现不满足的项目应在当前状态文档中明确列为缺口。
- 个人开发计划、进展报告和阶段汇报已被移除。它们不是当前事实来源；需要追溯历史时使用 Git 提交记录。
